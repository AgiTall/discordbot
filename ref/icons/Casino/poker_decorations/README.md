# Украшения покерных аватарок

Для каждого украшения нужны два прозрачных PNG:

- `<ключ>_normal.png` — обычное состояние;
- `<ключ>_active.png` — состояние во время хода игрока.

Требования:

- размер холста: **128×128 px**;
- формат: **PNG RGBA** с прозрачным фоном;
- круг аватара: **88×88 px** строго по центру;
- границы круга аватара: от `(20, 20)` до `(108, 108)`;
- не закрашивать центральный круг, иначе украшение перекроет лицо;
- оба варианта должны иметь одинаковое расположение элементов.

## Загрузка без Git

На сервере Discord выполните:

`/poker-frame-add`

Заполните:

- `name` — название товара;
- `price` — цена в обычных долларах;
- `normal` — обычный PNG;
- `active` — PNG во время хода;
- `key` — необязательный английский ключ.

Команда проверит файлы, сохранит оба изображения в PostgreSQL и сразу
добавит товар в магазин. Git, ручное копирование файлов и новый деплой не
требуются.

Для удаления используйте `/poker-frame-delete`.
